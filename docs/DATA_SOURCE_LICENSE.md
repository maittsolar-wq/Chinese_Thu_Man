# Chinese Thu Man — Data Source & License Policy v1.0

## Purpose
Track provenance and licensing for every external dataset.

## Critical rule
Internal/non-commercial use does not automatically remove copyright or license obligations.

## Source registry
Maintain:
`data/sources/SOURCES.md`

For every source record:
- name
- URL/repository
- purpose
- exact version/date
- license
- attribution requirement
- share-alike requirement
- files used
- modifications
- retrieval date

## HSK source
Select one explicit HSK 3.0 source as the primary level-mapping source. Verify its current license from the original source before shipping.

## Dictionary data
Do not assume a GitHub repository's software license covers all data files. Check repository license, data file notices, README and upstream source.

## CC BY
If used:
- provide attribution
- identify source
- identify modifications when required

## CC BY-SA
If used:
- provide attribution
- identify modifications
- review share-alike implications before redistributing adapted data

## Proprietary websites
Do not copy proprietary definitions, examples, audio or other content merely because it is publicly viewable.

## Generated/editorial content
Project-created Vietnamese meanings/examples should be marked as project-created/edited. Do not falsely attribute them to an external dictionary.

## Release checklist
- [ ] source identified
- [ ] version recorded
- [ ] license verified
- [ ] attribution recorded
- [ ] share-alike reviewed
- [ ] modifications documented
- [ ] proprietary content excluded
- [ ] attribution file prepared

This is an engineering/content governance guide, not legal advice. Re-check licensing before any future commercial release.
