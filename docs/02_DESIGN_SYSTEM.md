# Chinese Thu Man — Design System v1.0

## Visual direction
Clean, minimal educational WEB UI:
- white-first
- blue for emphasis
- rounded cards
- light borders
- subtle shadows
- generous whitespace
- strong typography hierarchy

## Primary color
`#025291`

Use for:
- active navigation
- primary buttons
- major headings
- selected cards
- links when appropriate
- progress indicators

## Background
Main page and navigation/sidebar: white.

The active navigation item is highlighted with primary blue.

## Semantic colors
- Success: green/light green
- Error: red/light red
- Hint: yellow/orange
- Neutral: light gray + dark charcoal

Do not add decorative colors without a clear reason.

## Cards
White background, rounded corners, light border, subtle shadow/bottom elevation.

## Buttons
Primary: #025291 background + white text.
Secondary: white background + blue border/text.
Correct: green treatment.
Incorrect: red/pink treatment.
Hint: yellow/orange treatment.

## Vocabulary hierarchy
```text
Chinese
Pinyin
Vietnamese meaning
```
Chinese is the strongest visual element.

## Practice options
Default: white + light border.
Correct: light green + green border.
Wrong: light red/pink + red border.

## Typography
Large bold blue page titles; clear section headings; dark charcoal body text; prominent Chinese characters; readable secondary Pinyin.

## Responsive WEB
Prevent overflow and keep controls usable at narrower browser widths. This is responsive web behavior, not a mobile-app design.

## Consistency
Use shared design tokens/components. Avoid one-off colors, inconsistent radii, shadows or button sizes.
