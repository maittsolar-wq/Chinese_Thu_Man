# UI Design System

## Visual language
- Clean educational web UI
- White background
- Primary blue
- Dark charcoal text
- Green = correct
- Red/pink = incorrect
- Yellow/orange = hint
- Light gray/blue = borders and inactive progress
- Rounded containers
- Generous whitespace
- Desktop-first web layout

## Typography
Page and section titles are large, bold and blue.
Supporting text is dark charcoal.
Chinese vocabulary is visually prominent.
Pinyin is secondary and visually separated from Chinese.

## Containers
Use white cards with rounded corners, thin light borders and subtle bottom/outer shadow. Avoid heavy shadows and gradients.

## Buttons
Primary:
- blue background
- white text
- rounded
- strong emphasis

Secondary:
- white background
- blue border/text

Error-related:
- red/pink treatment

## Answer options
Default: white, light border, rounded corners, subtle bottom shadow.
Correct: light green + green border/bottom emphasis.
Wrong: light red/pink + red border/bottom emphasis.

## Progress
Show `current/total` and a horizontal progress bar.
Calculate dynamically from session state.

## Navigation
Keep the existing web header and highlight `Luyện tập` when inside Practice.

## Responsive web
Preserve the desktop layout while preventing overflow at narrower browser widths. This is responsive WEB behavior, not a mobile-app implementation.
